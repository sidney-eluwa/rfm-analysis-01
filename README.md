# rfm-analysis-01

Customer RFM Segmentation & BI Dashboard

This project delivers an end-to-end customer segmentation pipeline and interactive BI dashboard for an online print and personalised-products retailer. Using twelve months of transactional data (January–December 2025), the project applies an RFM (Recency, Frequency, Monetary) framework to classify 285 customers into eight clearly defined behavioural segments, enabling the marketing team to take targeted, data-driven action on each group.
